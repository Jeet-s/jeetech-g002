# Pipe Puzzle Game

Rotate pipes, filters and mixers to solve 60 offline logic puzzles.

- Google Play: https://play.google.com/store/apps/details?id=com.jeetech.g002
- Privacy policy: https://jeet-s.github.io/jeetech-g002/privacy.html
- Current version: 1.0.6

`game/` is the Expo (React Native) source as shipped; `store/` holds the listing and graphics.
